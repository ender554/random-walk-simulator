# Gambler's Ruin: feature research (2026-10-28)

**How to be the best:** the only free browser lab where learners run timid, bold and popular betting systems side by side on the same seeded coin flips, with exact theory on every chart, so they see for themselves that no staking plan beats a negative edge.

Competitors:
- MetricGate: bet size, a game-length histogram, Kelly.
- Siegrist Red and Black: timid vs. bold play.
- Open-source betting simulators: Martingale, Fibonacci, D'Alembert.
- Bilkent: animation, speed control, survivors over time.
- PrimeDope: bands, drawdowns, a ruin-vs-bankroll table.
- Wolfram: expected duration.
- None of them has a share link or CSV export.

Evidence:
- Homework asks students to simulate doubling bets.
- Traders compare Martingale with flat betting.
- The core misconception (visualproof): "The martingale conflates sequence with edge".

Must:
- Bet size and strategy: flat, bold, Martingale with a table limit, D'Alembert, Fibonacci.
- A game-length histogram by outcome.
- A ruin-vs-starting-bankroll curve.
- 10k–100k games in stats-only mode.
- A share link.

Should:
- A strategy comparison table on the same seed.
- Animated playback with survivors over time.
- Craps and single-number presets with payouts.
- CSV export.
- A no-target / two-player framing.

Could:
- Kelly betting.
- A percentile fan chart.
