# Site-wide needs: research (2026-10-28)

What makes the best simulators loved:
- free, no login, run in any browser
- usable without instructions
- easy to drop into a lesson, with teacher guides
- short and well designed
- **predict before watching:** demonstrations only teach when students predict first (Crouch, Fagen, Callan & Mazur 2004)
- accessibility built in (PhET)
- students can bring their own data

Common complaints:
- no way to send work back to the teacher, so students hand in screenshots (Alice Keeler)
- too little explanation (Seeing Theory)
- tools that died with their platform (Java, Flash)
- slow on school laptops
- having to log in to save work
- interfaces that are hard to learn
- free-play areas that don't teach anything

Must:
- shareable URL state
- CSV export
- light / projector theme
- play/pause/step/speed controls and a reset
- keyboard and screen-reader basics
- a "predict, then test" prompt on each tool

Should:
- an embed snippet with `?embed=1`
- fullscreen and a QR code
- a teacher page for each tool
- image export options

Could:
- an offline PWA
- reduced motion and a color-blind-safe palette
